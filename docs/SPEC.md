# 한남랭 (가칭) 명세

대화형 스택 머신 + 늘임 표기 숫자. 확장자는 `.hnl`.

## 기본 규칙

- 한 줄이 한 번의 **발화**입니다. 발화 하나가 명령 하나예요.
- 프로그램은 `요이`로 시작해서 `넌 나가라`로 끝납니다.
- `아(`로 시작하는 줄은 주석(혼잣말)입니다. 빈 줄도 무시해요.
- **줄 번호**는 `요이` 다음 줄이 1번이고, 주석과 빈 줄은 세지 않습니다. IDE의 왼쪽 번호가 이 번호예요.
- 실행 모델은 정수 스택 하나입니다. 정수는 크기 제한이 없어요.

## 숫자: 늘임 토큰

`~` 개수가 한 자릿수입니다 (0~9). 숫자 리터럴은 한 줄 전체이고, 스택에 push 됩니다.

| 토큰 | 뜻 |
|---|---|
| `티원` | 0 |
| `티~원` | 1 |
| `티~~~~~~~~~원` | 9 |
| `지~랄` | 음수 부호, 첫 자릿수는 1 |

토큰을 이어 쓰면 자릿수가 늘어납니다. 부호는 **첫 토큰**이 정하고(`티…원`은 양수, `지…랄`은 음수), 뒤 토큰은 항상 `티…원`입니다.

| 값 | 표기 |
|---|---|
| 14 | `티~원 티~~~~원` |
| 100 | `티~원 티원 티원` |
| -14 | `지~랄 티~~~~원` |

## 명령

| 발화 | 동작 |
|---|---|
| 숫자 리터럴 | push |
| `줴줴이야` | pop 해서 숫자로 출력 |
| `줴줴이야!` | pop 해서 유니코드 문자로 출력 |
| `이지랄ㅋㅋ` | 표준 입력에서 정수 하나를 읽어 push (EOF면 -1) |
| `예?` | pop 해서 0이 아니면 **다음 줄(대답)**을 실행, 0이면 건너뜀 |
| `아뇨아뇨아뇨 <숫자>` | 그 줄 번호로 점프 |
| `넌 나가라` | 종료 (중간에 써도 됩니다) |
| `아~…` | 아래 스택 연산 (`~` 개수가 연산 번호) |

### 아 연산 (`~` 개수 = 번호)

`b`는 스택 맨 위, `a`는 그 아래 값입니다. 자주 쓰는 연산일수록 번호가 작아요.

| `~` | 연산 | 결과 |
|---|---|---|
| 0 `아` | dup | `a` → `a a` |
| 1 `아~` | add | `a+b` |
| 2 `아~~` | sub | `a-b` |
| 3 `아~~~` | swap | `a b` → `b a` |
| 4 `아~~~~` | over | `a b` → `a b a` |
| 5 `아~~~~~` | mul | `a*b` |
| 6 `아~~~~~~` | drop | 맨 위 버림 |
| 7 `아~~~~~~~` | div | `a/b` (0쪽으로 버림) |
| 8 `아~~~~~~~~` | mod | `a%b` (부호는 a를 따름) |
| 9 `아~~~~~~~~~` | less | `a<b`면 1, 아니면 0 |

## 대화 규칙

`예?`는 질문이라 반드시 대답(다음 줄)이 있어야 합니다. 다음 줄이 없거나 또 `예?`이면 실행 전에 에러가 나요.

```
예?                      ← 질문
아뇨아뇨아뇨 티~~원       ← 대답 (참일 때만 실행)
```

참/거짓 두 갈래는 대답 줄 뒤에 점프를 하나 더 두는 식으로 만듭니다. [examples/factorial.hnl](../examples/factorial.hnl)을 참고하세요.

## 에러

모든 에러는 `N번째 줄: …` 형태입니다. 스택이 비었을 때, 0으로 나눴을 때, 없는 줄로 점프했을 때, 질문에 질문으로 대답했을 때, 무한 루프(스텝 한도 초과)일 때 나요. CLI는 `에러: …`를 stderr에 출력하고 종료 코드 1을 돌려줍니다.
